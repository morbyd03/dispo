# Contribuer à Dispo

Les contributions sont les bienvenues.

Dispo est développé en collaboration avec ChatGPT (OpenAI),
sous la responsabilité humaine de son mainteneur.

## Proposer une amélioration

Les propositions peuvent concerner :

- Les fonctionnalités.
- L'ergonomie.
- La sécurité.
- Les performances.
- La documentation.
- Les tests automatisés.
- La compatibilité avec différents environnements.

## Développement

Créer une branche dédiée à chaque évolution.

Privilégier les modifications ciblées et documentées.

Exécuter les tests avant de proposer une modification :

    docker compose exec -T web python manage.py test planning

Ajouter des tests pour les nouvelles fonctionnalités
et les corrections importantes.

## Confidentialité

Ne jamais publier :

- Des informations personnelles concernant les agents.
- Des disponibilités opérationnelles réelles.
- Des bases de données.
- Des sauvegardes.
- Des mots de passe ou des clés secrètes.
- Des fichiers de configuration privés.
- Des logos personnels sans autorisation.

Utiliser uniquement des données fictives pour les tests.

## Intelligence artificielle

L'utilisation d'outils d'assistance par intelligence
artificielle est autorisée.

Les contributions doivent néanmoins être comprises,
relues et testées par leur auteur humain.
